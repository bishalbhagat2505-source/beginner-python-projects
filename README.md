# Beginner Python Projects

A collection of small Python projects I built while learning programming. These projects helped me practise writing functions, using loops and conditionals, handling user input and working with Python modules.

## Projects

| Project | Description |
|---|---|
| [Blackjack Game](./Blackjack_Game/) | A terminal-based Blackjack game using classes, objects and basic game logic |
| [Rock Paper Scissors](./Rock_Paper_Scissor/) | A simple player-versus-computer game with random choices and replay |

## How to run

1. Clone this repository.
2. Open the project folder in your terminal or Python IDE.
3. Run the relevant Python file.

For example:

```bash
python Blackjack_Game/Black_jack.py
```

## What I practise here

- Python basics, functions and control flow
- Classes and objects
- User input and input validation
- The `random` module
- Breaking small problems into steps

I'll add more small projects as I build them.
